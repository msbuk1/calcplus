# calcplus is GPL-3.0-only

calcplus is licensed under GPL-3.0-only. The repository carries `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, `CONTRIBUTING.md`, `CONTRIBUTORS.md` and the licensing note; every release publishes corresponding source and an SBOM.

**Considered options:** GPLv3 with the free HyperFormula edition (chosen); a proprietary licence with a commercial HyperFormula licence (possible, but requires relicensing every contribution); a permissive licence (impossible while using HyperFormula's GPL edition); a different engine (rejected on fidelity or fit).

**Why:** HyperFormula's GPL-3.0-only edition is the binding constraint. The project is open source, so GPLv3 is a fit rather than a compromise. Every distributed dependency is GPLv3-compatible.

**Consequences:** the browser bundle, launcher and hosted build must offer corresponding source and legal notices; no DRM that blocks modified builds; OFL fonts and original icons only; DCO sign-off instead of a CLA; a local licence gate and a release SBOM. See [licensing](../../.scratch/calcplus/spec/licensing.md) and [ticket 23](../../.scratch/calcplus/issues/23-licence-compliance.md).
