## What is already banked (read these first)

The M5 lanes built much of the round-trip machinery M6 must harden:

- **Byte-identical no-op saves and verbatim unknown-XML preservation** —
  `src/ooxml/autofilter-xml.ts` (parse-to-model with `raw` + a state key;
  untouched filters are never rewritten) and `src/ooxml/conditional-format-xml.ts`
  (base + x14 rule merging, `dxfs` append-only). These set the pattern for
  every remaining preserved feature (validation, comments, hyperlinks,
  protection, print setup).
- **The part patch writer with row/column renumbering** —
  `src/ooxml/patch/*` plus `src/ooxml/structure-patch.ts` (structural edits
  renumber `<row r>`, cell `r`, `<col min/max>`, dimension/merge/hyperlink/
  sqref refs while keeping unmodelled children and untouched parts
  byte-identical).
- **The range-transform module** — `src/model/range-transform.ts` hardens
  formulas, merges, names, CF/validation sqrefs and filter ranges through
  structural edits, with typed block results. M6 extends it to drawing
  anchors, chart series ranges and pivot source ranges, and closes its
  follow-ups (Tier B anchors; unsupported formula constructs must never leave
  silently stale text).
- **Reporting hooks** — unsupported-rule listing is exposed
  (`conditional-format-xml.ts`); the compatibility and export reports consume
  it.
- **Command transactions** — one structural edit is one undo transaction with
  an exact inverse (`src/commands/structure.ts`, `session.ts`).

## Scope recap

Full `.xlsx` round-trip (styles/shared strings append-only, cached results,
shared and array formulas, comments and threaded comments, hyperlinks,
validation, CF, names, protection, print setup); preserved parts (charts,
images, shapes, pivots and caches, external links, VBA, signatures, tables,
slicers, sparklines, custom XML, custom properties); structural range
transforms across all range-bearing constructs — **transform or block, never a
silently stale anchor**; compatibility and export reports; the producer matrix
(Excel 365/2019, LibreOffice, Google Sheets, openpyxl, SheetJS, xlsx-populate);
hostile-input caps and XXE-safe parsing.

## Where to start

Fixture authoring may start before the M5 exit (the plan allows it; only the
M6 exit gate is gated on M5). Start with the fixture corpus in `fixtures/compat/`
generated by `scripts/generate-fixtures.mjs` — extend the generator for F2-F24
per `file-compat.md` §9, and wire identity (F1-F2), styles/strings/caches
(F3-F7), formulas (F8) first; the object fixtures (F9-F12) and hostile fixtures
(F18-F21) follow the existing patterns in `tests/ooxml-save.test.ts` and
`tests/m5-filter-roundtrip.test.ts`.

## Process rules (standing)

- Contracts beat code summaries; scope changes go through the feature matrix
  and a ticket (`.scratch/calcplus/issues/`); architecture changes get an ADR
  in `docs/adr/`.
- Checks run on the maintainer's computer only; nothing runs on GitHub.
- Every commit is signed off (`git commit -s`).
- `npm run inventory` is the command-map gate; the map
  (`src/commands/command-inventory.json`) is authoritative for chrome.
- Goldens and fixture changes are reviewed like code; a diff that only updates
  expectations is flagged.
